Features

Everything you need to
query faster

Built for ServiceNow power users who live in list views and need queries done right, right now.

🔍

Dynamic Field Autocomplete

Fields are fetched live from your ServiceNow instance — including inherited fields from parent tables — so you always get the full picture.

➕

Multi-Condition Builder

Stack as many conditions as you need with the chip-based builder. Commit each condition with Ctrl+Enter and keep going without losing context.

🔗

Reference Field Resolver

Type a display name and get the sys_id back instantly. No more hunting through SN to copy IDs for reference field queries.

⭐

Saved Templates

Save your most-used queries as named templates. Export them as JSON to share with your team or import them on another machine.

⌨️

Keyboard First

Tab to navigate, arrow keys for dropdowns, Enter to search, Ctrl+Enter to add a condition. Your hands never have to leave the keyboard.

⚡

Smart Field Cache

Fields are cached per-instance for 1 hour so the popup opens instantly. Hit the refresh button any time to bust the cache and get fresh data.

How it works

From zero to query
in seconds

No configuration needed. Open a ServiceNow tab, click the extension, and start building.

01

Open any ServiceNow tab

The extension automatically detects your instance and authenticates using your existing session — no credentials stored.

02

Pick your table

Choose from common ITSM and CMDB tables, or type any custom table name. Fields load automatically from the live instance.

03

Build your conditions

Search and select fields by label or API name, pick an operator, enter a value. Add as many conditions as you need with the chip builder.

04

Hit Search

The extension builds the full sysparm_query URL and navigates your SN tab directly to the filtered list view. Done.
